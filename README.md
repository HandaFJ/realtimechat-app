# リアルタイムチャットアプリ

WebSocket を使った、LINE 風の吹き出しレイアウトのリアルタイムチャットです。
Svelte のトランジション／アニメーションで、メッセージの追加や画面切り替えを滑らかに見せています。

## 主な機能

- 名前を入力して参加、退出
- メッセージのリアルタイム送受信（全員に配信）
- 自分は右側、相手は左側の吹き出し
- 参加・退出の通知と、現在の接続人数の表示
- 入力欄をフッターに固定（スマホのアドレスバーやホームバーにも対応）
- 無操作が続くと自動で切断
- 日本語入力（IME）の変換確定 Enter では送信されない

## ローカルで動かす

### 必要なもの

- [Deno](https://deno.com/)
- [Node.js](https://nodejs.org/)（v22 推奨）

### 1. リポジトリを取得

```bash
git clone https://github.com/ユーザー名/リポジトリ名.git
cd リポジトリ名
```

### 2. サーバーを起動

```bash
deno run --allow-net --allow-env server.ts
```

`ws://localhost:8080` で待ち受けます。このターミナルは開いたままにしてください。

### 3. フロントエンドを起動

別のターミナルを開いて実行します。

```bash
cd client
npm install
npm run dev
```

表示された URL（通常は `http://localhost:5173`）をブラウザで開いてください。

### 4. 動作を確認

ブラウザのタブを2つ開き、それぞれ別の名前で参加します。
片方で送ったメッセージがもう片方にも表示され、参加・退出の通知や人数が更新されれば成功です。

## 設定（必要な場合のみ）

通常は設定なしで動きます。ポートを変えたい場合などは、以下を使ってください。

### サーバーの環境変数

| 変数                   | 内容                                  | デフォルト                                    |
| ---------------------- | ------------------------------------- | --------------------------------------------- |
| `PORT`                 | 待ち受けポート                        | `8080`                                        |
| `ALLOWED_ORIGINS`      | 接続を許可する Origin（カンマ区切り） | `http://localhost:5173,http://127.0.0.1:5173` |
| `IDLE_TIMEOUT_MINUTES` | 無操作で自動切断するまでの時間（分）  | `10`                                          |

例: ポートを 9000 にして、自動切断を1分にする

```bash
PORT=9000 IDLE_TIMEOUT_MINUTES=1 deno run --allow-net --allow-env server.ts
```

### フロントエンドの接続先

サーバーのポートを変えた場合は、`client/.env.local` を作成して接続先を指定します。

```
VITE_WS_URL=ws://localhost:9000
```

設定後は `npm run dev` を再起動してください。

## うまく動かないとき

| 症状                                           | 確認すること                                                                                                                                                                                                                                |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「サーバーに接続できませんでした」と表示される | サーバーが起動しているか、`VITE_WS_URL` のポートが合っているか確認してください。                                                                                                                                                            |
| 接続が拒否される（403）                        | フロントエンドの URL が `ALLOWED_ORIGINS` に含まれているか確認してください。Vite が `5173` 以外のポートで起動した場合は、そのポートを追加します。<br>例: `ALLOWED_ORIGINS=http://localhost:5174 deno run --allow-net --allow-env server.ts` |
| `Address already in use` と出る                | `8080` が使用中です。`PORT` を変えて起動してください。                                                                                                                                                                                      |
| しばらくすると入室画面に戻る                   | 無操作による自動切断です。`IDLE_TIMEOUT_MINUTES` で時間を変更できます。                                                                                                                                                                     |

## 補足

- メッセージの配信には `BroadcastChannel` を使っています。複数のインスタンスで動く環境でも全員に届くようにするためで、ローカルの1プロセスでは通常どおり動作します。ただし、表示される接続人数は接続先のインスタンスごとの数で、全体の人数とは限りません。
- メッセージは 500 文字、名前は 20 文字までに制限しています。
- 時刻の表示は日本時間（`Asia/Tokyo`）に固定しています。
